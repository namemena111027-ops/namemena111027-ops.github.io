Radius

c 型連續圓角，為什麼不用 border-radius？

一般的 border-radius 是「直線＋四分之一圓」：直線的曲率是 0，接上圓弧的瞬間突然變成 1/r，交接處看得出一個折點。參考圖 c 的輪廓是「直線 → 曲率逐漸增加 → 一段等曲率圓弧 → 逐漸減少 → 直線」，邊緣的過渡更平順。

規則內容
組成每個角＝三次貝茲曲線＋圓弧＋三次貝茲曲線
角的延伸長度e＝1.2 × 設計圓角 r。例如 r＝24px 的卡片，從距離邊角 28.8px 處開始彎
曲線常數A＝0.18977、B＝0.40455、QX＝0.58895、QY＝0.08722；圓弧半徑＝0.6797e
小尺寸e 不超過短邊的一半，避免四個角互相重疊
畫法JavaScript 依元素的實際像素尺寸產生 clip-path: path()；CSS 只保留 border-radius 作為不支援時的備援
更新時機ResizeObserver 只在尺寸改變時重算；動畫進行中逐格同步；捲動時不計算
電腦版視窗 ≥ 820px 起，大面積元件的圓角隨寬度連續放大，最多 1.3 倍；手機寬度完全不變

細線框125%／150% 縮放時，對齊整數裝置像素

Engineering

單一 HTML 檔，分成清楚的模組。

網站是一個靜態 HTML 檔（CSS、JavaScript、肖像都內嵌），部署在 GitHub Pages，沒有使用框架，也沒有建置工具。V2.0 新增的案例頁共用同一份樣式與動效程式。

模組負責
c 型圓角引擎依實際尺寸產生每個元件的輪廓
動畫工具貝茲曲線、逐格補間、動畫中同步輪廓
捲動驅動站內所有程式捲動共用；使用者一觸碰就停
滑塊引擎分段控制與導覽的 SVG 滑塊、動態模糊
聚焦框鍵盤聚焦時的 c 型外框

元件線索工作台、預約示範、報告手風琴、說明標籤、肖像放大、冰箱示範
無障礙（V2.0）inert 同步、焦點返回
